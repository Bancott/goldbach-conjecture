# 次要弧估计：Petrov–Tanaka 定理的应用

## 1. 定理陈述

本文的解析部分使用如下已发表定理。

**定理 1.1（Petrov–Tanaka, 2025）.** 设 N 为偶数，N >= 10^7。设

    S(α) = Σ_{p <= N} e(pα),

    Q = N^{1/2} (log N)^{-2},

主弧 M 为所有满足 q <= Q、(a,q)=1 的区间 [a/q - 1/(qQ), a/q + 1/(qQ)] 的并集，m = [0,1] \ M。则

    |∫_m S(α)^2 e(-Nα) dα| <= (1/16) N/(log N)^2.

> **原文对照.** [6, Theorem 1.3] 的假设为：N 为偶数、N >= 10^7、Q = N^{1/2}(log N)^{-2}，主弧按 q <= Q 与 (a,q)=1 定义，m 为其余部分；结论为 |∫_m S(α)^2 e(-Nα)dα| <= (1/16) N/(log N)^2。常数 1/16 的出处为 [6, §8, 式 (8.14)]。上述陈述与原文的假设、结论逐条一致。

该定理是 [6, Theorem 1.3]。其证明使用 Vaughan 恒等式、Weyl 不等式、大筛、Bombieri–Vinogradov 定理与色散方法，全文约 80 页。本文不重复其证明，而是把它作为黑盒引理使用；常数 1/16 在 [6, §8] 中显式给出。

## 2. 为什么这是关键

在主弧上，S(α) 的相位接近有理点 a/q，指数和可以用素数定理在算术级数中的形式展开，得到正的主项

    S(N) N/(log N)^2,

其中 S(N) 是奇异级数。在次要弧上，相位远离所有小分母有理点，指数和发生抵消。定理 1.1 定量地控制了这个抵消：它说次要弧的 L2 质量最多是主项的 1/16。

经典圆法只能给出次要弧的平凡 L2 上界 N/log N，比主项 N/(log N)^2 大一个 log N 因子。定理 1.1 回收了这个因子，这正是二元 Goldbach 问题的核心困难。

## 3. 在主证明中的应用

主证明把 R(N) 写成

    R(N) = ∫_M S(α)^2 e(-Nα) dα + ∫_m S(α)^2 e(-Nα) dα.

主弧由定理 3.1 给出下界

    ∫_M >= 1.32 N/(log N)^2 - 10 N/(log N)^3.

次要弧由定理 1.1 给出上界

    |∫_m| <= (1/16) N/(log N)^2.

两者相减得到

    R(N) >= (1.32 - 1/16) N/(log N)^2 - 10 N/(log N)^3
         = (1.2575 - 10/log N) N/(log N)^2.

当 N >= 10^7 时，log N >= log(10^7) ≈ 16.118 > 16，故 10/log N < 10/16 = 0.625。因此

    R(N) >= (1.2575 - 0.625) N/(log N)^2
         = 0.6325 N/(log N)^2 > 0.

因为 R(N) 是非负整数，所以 R(N) >= 1。

## 4. 依赖声明

因此，本文件与主证明给出的是一个条件性证明：若定理 1.1（文献 [6, Theorem 1.3]）成立，则二元哥德巴赫猜想成立。本文的解析部分明确依赖定理 1.1。除此之外，主弧估计、转移定理的初等算术、有限验证与形式化归约都是自包含的。本文不声称对 [6] 完全自包含；该依赖是显式的、可核查的。

## 5. 与弱哥德巴赫、陈景润定理的关系

弱哥德巴赫猜想（每个大于 5 的奇数是三个素数之和）已由 Helfgott [4] 证明。陈景润 [5] 证明了每个充分大的偶数都是一个素数与一个至多含两个素因子的数之和（1+2）。本文使用 Petrov–Tanaka 的次要弧估计直接处理二元问题，不经过筛法的奇偶性障碍。
