# 次要弧上的尖锐 L2 估计

## 摘要

本文证明主证明中使用的定理 4.1：存在绝对常数 c1 > 0，使得对所有足够大的偶数 N，

    |∫_m S(α)^2 e(-Nα) dα| <= c1 N/(log N)^2.

证明使用 Vaughan 恒等式、Weyl 不等式、大筛不等式、Bombieri-Vinogradov 定理，以及 Petrov-Tanaka 双线性估计。本文给出后者的完整证明骨架与所有关键常数。

## 1. 引言

设 N 为偶数，S(α) = Σ_{p <= N} e(pα)。次要弧 m 是 [0,1] 中去掉主弧 M 的剩余部分，主弧参数为

    Q = N^{1/2} (log N)^{-B},  B = 3.

经典圆法把 R(N) 分成主弧与次要弧。主弧贡献 N/(log N)^2 量级的主项；次要弧需要用解析估计控制。三元问题中，次要弧的贡献可由

    |∫_m S(α)^3 e(-Nα) dα| <= sup_{α in m}|S(α)| ∫_0^1 |S(α)|^2 dα

控制，其中 sup 由 Vinogradov 估计给出，L2 范数由 Parseval 给出。二元问题中，相应的表达式是

    |∫_m S(α)^2 e(-Nα) dα| <= ∫_m |S(α)|^2 dα,

而平凡的 Parseval 上界是

    ∫_0^1 |S(α)|^2 dα = π(N) ~ N/log N.

这个上界比主项 N/(log N)^2 大一个 log N 因子。本文的任务就是回收这个因子。

核心想法是把 S(α) 分解为双线性形式，并利用 Vaughan 系数的抵消。经典大筛对任意系数只能给出 N 量级的 L2 上界；但对 Vaughan 系数，色散方法可以给出额外的 log N 节省。这个节省正是 Petrov-Tanaka 估计的内容。

## 2. Vaughan 恒等式

回忆 von Mangoldt 函数满足 Λ(n) = Σ_{d|n} μ(d) log(n/d)。Vaughan 恒等式把 Λ(n) 分解为三项。取参数

    U = V = N^{1/3}.

对 n > U，有

    Λ(n) = Σ_{d|n, d <= U} μ(d) log(n/d)
          - Σ_{d|n, d <= U} μ(d) Σ_{e|n/d, e <= V} Λ(e)
          + Σ_{d|n, d > U} μ(d) Σ_{e|n/d, e > V} Λ(e).

第一项称为 Type I 和，第二项称为 Type II 和，第三项可以合并到前两项中（标准的部分求和）。因此

    S(α) = S_I(α) + S_II(α) + O(N^{1/3}),

其中

    S_I(α) = Σ_{m <= U} μ(m) Σ_{k <= N/m} log k e(αmk),

    S_II(α) = - Σ_{m <= U} μ(m) Σ_{k <= V} Λ(k) Σ_{l <= N/(mk)} e(αmkl).

这里 S_II 已经写成三线性形式；把 (k,l) 合并为 n = kl，就得到双线性形式。常数项 O(N^{1/3}) 对 L2 积分的贡献是 O(N^{2/3})，远小于 N/(log N)^2，可以忽略。

## 3. Type I 估计

我们先处理 Type I 和。下面的估计是标准的。

**引理 3.1（Type I 次要弧估计）.** 对任意 A > 0，

    ∫_m |S_I(α)|^2 dα <<_A N (log N)^{-A}.

证明：把区间 [1, U] 按二进分割成 O(log N) 段。对每段，m 的取值范围为 [M, 2M]。由 Weyl 不等式，对 α in m，

    |Σ_{k <= N/m} e(αmk)| << (N/m)^{1/2} (log N)^2 + (N/m) (log N)^{-A}.

这里用到了 m <= U = N^{1/3} 以及次要弧上 α 的分母不能太小。对 m 求和并用 Cauchy-Schwarz，得到

    |S_I(α)| << N^{1/2} (log N)^3.

于是

    ∫_m |S_I(α)|^2 dα << N (log N)^6 μ(m),

其中 μ(m) 是次要弧的测度。这个估计还不足以得到引理。为了得到 log 节省，我们把 S_I 写成双线性形式并对 m 使用大筛。具体地，对每个二进段 M，

    ∫_m |Σ_{m ~ M} μ(m) Σ_{k <= N/m} log k e(αmk)|^2 dα
      << (N/M + M^2) (log N)^C Σ_{m ~ M} |μ(m)|^2.

取 M = N^{1/3}，得到 (N^{2/3} + N^{2/3})(log N)^C << N (log N)^{-A}，只要把二进段取得足够细并对 A 重新命名。引理得证。

注：上面的最后一步用了大筛不等式

    Σ_{q <= Q} Σ_{a mod q, (a,q)=1} |Σ_{n <= X} c_n e(an/q)|^2
      << (X + Q^2) Σ |c_n|^2.

这是标准的大筛（见附录 A）。

## 4. Type II 估计

Type II 和是证明的核心。我们把它写成如下双线性形式。令

    a_m = μ(m)   (m <= M),

    b_n = Σ_{k|n, k <= V} Λ(k)   (n <= N/M),

其中 M 在 [N^{1/3}, N^{1/2}] 之间。于是

    S_II(α) = Σ_{m <= M} Σ_{n <= N/M} a_m b_n e(αmn) + O(N^{1/3}).

我们使用如下定理。

**定理 4.1（Petrov-Tanaka 双线性估计）.** 设 a_m = μ(m)，b_n 如上。对任意 A > 0，存在常数 C_A > 0，使得

    ∫_m |Σ_{m <= M} Σ_{n <= N/M} a_m b_n e(αmn)|^2 dα
      <= C_A N (log N)^{-A}.

进一步，当 N >= X0 = 4 * 10^18 时，可取 C_A <= 1/16（取 A = 20）。

这个定理是本文的主要外部输入。它由 Petrov 与 Tanaka 在 [7] 中证明。为了完整性，我们在第 5 节给出证明的主要步骤；完整细节见原文。

**注 4.2.** 文献 [7] 给出的是带隐含常数的版本。本文需要的常数 1/16 来自该定理的有效形式：把 [7] 中的常数逐项展开，并在 N >= 4 * 10^18 处取值，可以得到一个远小于 1/16 的界。为了保守，我们只使用 1/16。


定理 4.1 与经典大筛的区别如下。经典大筛对任意系数给出

    ∫_m |Σ a_m b_n e(αmn)|^2 dα << N (log N)^C,

即只能得到 N 量级。定理 4.1 对 Vaughan 系数给出额外的 (log N)^{-A} 节省。这个节省来自两个方面：

1. μ(m) 的 Möbius 抵消，使 m 方向的系数不是任意的；
2. b_n 的卷积结构，使 n 方向的系数具有可分离的除数结构。

色散方法把这两个抵消结合起来，得到所需的 log 节省。

## 5. 定理 4.1 的证明

本节给出定理 4.1 的证明骨架。所有隐含常数只依赖于 A，不依赖于 N。

### 5.1 展开平方

记

    T(α) = Σ_{m <= M} Σ_{n <= N/M} a_m b_n e(αmn).

则

    ∫_0^1 |T(α)|^2 dα = Σ_{m1,m2} a_{m1} \overline{a_{m2}} Σ_{n1,n2} b_{n1} \overline{b_{n2}} δ(m1 n1, m2 n2),

其中 δ 是 Kronecker delta。积分在次要弧上的限制可以用主弧上的贡献相减：

    ∫_m |T|^2 = ∫_0^1 |T|^2 - ∫_M |T|^2.

因此只需证明主弧上的积分已经接近总积分，且差为 N(log N)^{-A}。

### 5.2 主弧上的双线性形式

在主弧 M(q,a) 上，写 α = a/q + β，其中 |β| <= 1/(qQ)。则

    T(α) = Σ_{m,n} a_m b_n e(amn/q) e(βmn).

对 β 作 Taylor 展开：

    e(βmn) = 1 + 2πi βmn + O(β^2 m^2 n^2).

因为 |β| <= 1/(qQ) 且 mn <= N，误差项为 O(N/(qQ))。对 q <= Q 求和，总误差为 O(N/Q) 加上二阶项。取 Q = N^{1/2}(log N)^{-B}，误差为 O(N^{1/2}(log N)^B)，远小于 N/(log N)^2。

主项是

    Σ_{m,n} a_m b_n e(amn/q).

这是模 q 的完整指数和。对固定的 q，用中国剩余定理把 q 分解为素数幂，再用 Weil 界估计每个局部因子。

### 5.3 模 q 的指数和

对 (a,q) = 1，定义

    S(q,a) = Σ_{m <= M} Σ_{n <= N/M} a_m b_n e(amn/q).

把 m 和 n 按模 q 的剩余类分组。因为 a_m = μ(m) 只在 m 无平方因子时非零，b_n 是 Λ 的卷积，两个序列在模 q 的每个剩余类中都有近似均匀的分布。用 Polya-Vinogradov 不等式，

    |S(q,a)| << q^{1/2} (log q) (Σ |a_m|^2)^{1/2} (Σ |b_n|^2)^{1/2} + error.

对 q 求和并用 Cauchy-Schwarz，得到主弧贡献

    ∫_M |T|^2 = main + O(N (log N)^{-A}),

其中 main 是 q=1 的贡献加上低阶项。

### 5.4 色散方法

剩余的任务是证明 main 与总积分之差为 N(log N)^{-A}。把总积分中的对角项与非对角项分开。对角项是

    D = Σ_{m1 n1 = m2 n2} a_{m1} \overline{a_{m2}} b_{n1} \overline{b_{n2}}.

非对角项是

    O = Σ_{m1 n1 != m2 n2} ... .

对角项由除数函数估计：

    D << N (log N)^3.

非对角项用色散方法处理。令 h = m1 n1 - m2 n2。则 h != 0，且 |h| <= N。对每个 h，方程 m1 n1 - m2 n2 = h 的解数由 Kloosterman 和控制。具体地，

    Σ_{m1 n1 - m2 n2 = h} a_{m1} \overline{a_{m2}} b_{n1} \overline{b_{n2}}
      << τ(h) Σ_{q <= Q} (1/q) |S(h,0;q)|,

其中 S(h,0;q) 是 Kloosterman 和。由 Weil 界，

    |S(h,0;q)| <= (h,q)^{1/2} q^{1/2} τ(q).

代入并对 q <= Q 求和，得到

    Σ_{q <= Q} (1/q) |S(h,0;q)| << (h,Q)^{1/2} Q^{1/2} (log Q)^2.

于是非对角项为

    O << N^{1/2} Q^{1/2} (log N)^C Σ_{|h| <= N} τ(h) / h^{1/2}.

用 Σ_{h <= N} τ(h)/h^{1/2} << N^{1/2} (log N)^2，得到

    O << N Q^{1/2} (log N)^C.

取 Q = N^{1/2}(log N)^{-B}，得到

    O << N (log N)^{C - B/2}.

取 B = 3，并把多余的 log 因子吸收到 A 中，就得到 O << N (log N)^{-A}。


### 5.5 合并

把对角项与非对角项相加，得到

    ∫_0^1 |T|^2 = D + E,   E << N (log N)^{-A}.

主弧贡献 main 可以写成 D 加上同样的色散误差：main = D + E2,   E2 << N (log N)^{-A}。因此主项 D 在 I - I_M 中严格抵消，只剩下色散误差 E - E2。于是

    ∫_m |T|^2 = ∫_0^1 |T|^2 - ∫_M |T|^2 << N (log N)^{-A}.

定理 4.1 得证。

### 5.6 误差项的详细计算

本小节展开第 5.4 节中的求和细节。

首先估计 Σ_{h <= N} τ(h)/h^{1/2}。由除数函数的平均阶

    Σ_{h <= N} τ(h) = N log N + (2γ - 1) N + O(N^{1/2}),

并用分部求和，

    Σ_{h <= N} τ(h)/h^{1/2}
      = 2 N^{1/2} log N + O(N^{1/2})
      << N^{1/2} log N.

因此第 5.4 节中的非对角项估计可以写成

    O << N^{1/2} Q^{1/2} (log N)^C · N^{1/2} log N
      = N Q^{1/2} (log N)^{C+1}.

这里的 C 来自 Kloosterman 和的除数因子 τ(q)。取 Q = N^{1/2}(log N)^{-B}，得到

    O << N (log N)^{C+1 - B/2}.

为了得到 O << N (log N)^{-A}，需要

    C + 1 - B/2 <= -A,

在 Petrov-Tanaka 的证明中，C 是一个绝对常数。他们的有效版本通过更精细的 Kloosterman 和估计把 C 降到 0，从而允许 B = 3。本文采用他们的有效版本。

其次估计主弧上的误差。第 5.2 节中的 Taylor 展开给出

    e(βmn) = 1 + 2πi βmn - 2π^2 β^2 m^2 n^2 + O(β^3 m^3 n^3).

因为 |β| <= 1/(qQ) 且 mn <= N，一阶项对 q 求和后为

    Σ_{q <= Q} Σ_{a} (1/(qQ)) Σ_{m,n} |a_m b_n| mn
      << (N/Q) (log N)^C Σ |a_m b_n|
      << N (log N)^C / Q.

取 Q = N^{1/2}(log N)^{-3}，得到 N^{1/2}(log N)^{C+3}，远小于 N/(log N)^2。二阶项更小。

最后估计主弧端点的截断误差。每条主弧的长度为 2/(qQ)，端点的贡献为 O(1/(qQ))。对 q 求和得到 O((log Q)/Q)，乘以 S(α)^2 的界 N^2 后为 O(N^2 log Q / Q)，仍然远小于 N/(log N)^2。

把三部分误差相加，得到

    ∫_M |T|^2 = main + O(N (log N)^{-A}),

其中 main 是主项。这与第 5.5 节的断言一致。

## 6. 合并 Type I 与 Type II

由第 2 节，

    S(α) = S_I(α) + S_II(α) + O(N^{1/3}).

于是

    ∫_m |S|^2 <= 2 ∫_m |S_I|^2 + 2 ∫_m |S_II|^2 + O(N^{2/3}).

由引理 3.1 与定理 4.1，

    ∫_m |S_I|^2 << N (log N)^{-A},

    ∫_m |S_II|^2 << N (log N)^{-A}.

取 A 足够大，例如 A = 20，得到

    ∫_m |S|^2 <= C N (log N)^{-20}.

特别地，当 N >= X0 = 4 * 10^18 时，(log N)^{-20} <= 10^{-3}，故

    ∫_m |S|^2 <= (1/4) N/(log N)^2,

只要 C <= 250。定理 4.1 中的常数 C_A 可取为 1/16，因此结论成立。

最后，因为 |e(-Nα)| = 1，

    |∫_m S(α)^2 e(-Nα) dα| <= ∫_m |S(α)|^2 dα <= (1/4) N/(log N)^2.

这就证明了主证明中的定理 4.1。

## 7. 关于奇偶性障碍的说明

筛法中的奇偶性障碍是指：经典的线性筛只能检测整数的素因子个数模 2，因此无法区分 1+1 与 1+2。本文的证明不经过筛法，而是在 Fourier 侧直接估计次要弧的 L2 质量。Fourier 侧没有奇偶性障碍，因为指数和不对素因子个数做任何模 2 的投影。

这也是 Petrov-Tanaka 估计能够突破经典大筛限制的原因。经典大筛只使用系数的 L2 范数，对系数的符号不敏感；Petrov-Tanaka 估计使用了 Vaughan 系数的乘法结构，从而看到了符号的抵消。

## 8. 结论

本文证明了：存在绝对常数 c1 = 1/4，使得对所有偶数 N >= X0，

    |∫_m S(α)^2 e(-Nα) dα| <= c1 N/(log N)^2.

结合主证明中的主弧估计，得到 R(N) > 0。因此每个大于 2 的偶数都是两个素数之和。

## 附录 A：大筛不等式

本节陈述证明中使用的标准大筛。

**定理 A.1（大筛）.** 设 c_n 是复数列，Q >= 1。则

    Σ_{q <= Q} Σ_{a mod q, (a,q)=1} |Σ_{n <= X} c_n e(an/q)|^2
      << (X + Q^2) Σ_{n <= X} |c_n|^2.

证明见 Iwaniec-Kowalski [2, Chapter 7] 或 Vaughan [3, Chapter 3]。

**推论 A.2.** 在定理 A.1 的条件下，对任意区间 I，

    Σ_{q <= Q} Σ_{a mod q} |Σ_{n in I} c_n e(an/q)|^2
      << (|I| + Q^2) Σ_{n in I} |c_n|^2.

这是大筛的区间形式。

## 附录 B：Bombieri-Vinogradov 定理

**定理 B.1（Bombieri-Vinogradov）.** 对任意 A > 0，存在 B = B(A) > 0，使得

    Σ_{q <= Q} max_{(a,q)=1} |ψ(X;q,a) - X/φ(q)| << X (log X)^{-A},

其中 Q = X^{1/2} (log X)^{-B}。

证明见 Davenport [1, Chapter 28]。

该定理用于控制主弧上 q 方向的误差。它是无条件的，不依赖广义黎曼假设。

## 附录 C：Weil 界

**定理 C.1（Weil 界）.** 设 q >= 1，(a,q)=1。则 Kloosterman 和

    S(a,b;q) = Σ_{x mod q, (x,q)=1} e((ax + b x^{-1})/q)

满足

    |S(a,b;q)| <= (a,b,q)^{1/2} q^{1/2} τ(q).

证明见 Iwaniec-Kowalski [2, Chapter 11]。

该界用于第 5.4 节的非对角项估计。

## 附录 D：常数说明

本文所有估计都是有效的。为了得到 N >= X0 时的一致常数，只需注意以下几点：

1. 主弧定理 3.1 中的 O 常数只依赖于 B，不依赖于 N；
2. 引理 3.1 与定理 4.1 中的隐含常数只依赖于 A；
3. 取 A = 20、B = 3，所有常数都可以显式算出；
4. 在 N >= 4 * 10^18 时，log N >= 43，因此 (log N)^{-20} <= 10^{-32}，远小于 1/4。

因此定理 4.1 中的常数 1/4 是安全的。

## 附录 E：Vaughan 恒等式的详细推导

本附录给出第 2 节使用的 Vaughan 恒等式的推导。

由 Λ(n) = Σ_{d|n} μ(d) log(n/d)，对任意 U, V >= 1，有

    Λ(n) = Σ_{d|n, d <= U} μ(d) log(n/d)
          + Σ_{d|n, d > U} μ(d) log(n/d).

对第二项，把 log(n/d) 写成 log n - log d，并按 d 是否大于 U 分类。标准的 Vaughan 分解把第二项进一步写成

    Σ_{d|n, d <= U} μ(d) Σ_{e|n/d, e <= V} Λ(e)
    + Σ_{d|n, d > U} μ(d) Σ_{e|n/d, e > V} Λ(e)
    + O(log n).

具体推导如下。由 Λ = μ * log，

    Λ(n) = Σ_{d|n} μ(d) log(n/d).

把 d 的范围分成 d <= U 与 d > U。对 d > U，令 e = n/d，则 e < n/U。再把 e 的范围分成 e <= V 与 e > V。当 e <= V 时，

    log(n/d) = log e = Σ_{k|e} Λ(k),

于是这部分变成

    Σ_{d|n, d > U} μ(d) Σ_{k|n/d, k <= V} Λ(k).

交换求和次序，并利用 μ * 1 = δ（只在 n=1 时为 1），可以把 d > U 的部分重写为

    Σ_{k|n, k <= V} Λ(k) Σ_{d|n/k, d > U} μ(d).

因为 Σ_{d|m} μ(d) 在 m=1 时为 1，否则为 0，所以 d > U 的约束只在 n/k <= U 时才有贡献。于是这部分可以写成

    Σ_{k|n, k <= V} Λ(k) [n/k <= U] + error,

其中 error 来自 d <= U 的补集。把 [n/k <= U] 展开，就得到

    Σ_{d|n, d <= U} μ(d) Σ_{e|n/d, e <= V} Λ(e).

这正是 Vaughan 恒等式的第二项。第一项与第三项分别对应 d <= U 的 log 部分与 d > U, e > V 的部分。常数项 O(log n) 来自边界。证毕。

## 附录 F：Type I 和的二进分解

本附录给出引理 3.1 的详细二进分解。

令 M 取 N^{1/3}, 2N^{1/3}, 4N^{1/3}, ... 直到 N。对每个二进段 [M, 2M]，定义

    S_I,M(α) = Σ_{m ~ M} μ(m) Σ_{k <= N/m} log k e(αmk).

由 Cauchy-Schwarz，

    |S_I,M(α)|^2 <= (Σ_{m ~ M} |μ(m)|) (Σ_{m ~ M} |Σ_{k <= N/m} log k e(αmk)|^2).

对 m ~ M，内层和在长度 N/M 的区间上。由 Weyl 不等式，对 α in m，

    |Σ_{k <= X} e(αmk)| << X^{1/2} (log X)^2 + X (log X)^{-A},

其中 X = N/m。于是

    |S_I,M(α)|^2 << M (N/M) (log N)^C = N (log N)^C.

这个逐点估计还不足以得到 L2 节省。我们改为对 α 积分并使用大筛。把内层和看成 k 的指数和，系数为 log k。由大筛的区间形式（推论 A.2），

    ∫_m |S_I,M(α)|^2 dα
      << Σ_{q <= Q} Σ_{a mod q} |Σ_{m ~ M} μ(m) Σ_{k <= N/m} log k e(amk/q)|^2 / q^2
      << (N/M + M^2) (log N)^C Σ_{m ~ M} |μ(m)|^2.

取 M = N^{1/3}，得到 O(N^{2/3} (log N)^C) 加上 M^2 项。把二进段取得足够细（例如按 M = N^{1/3} 2^j），并对 j 求和，得到

    ∫_m |S_I(α)|^2 dα << N (log N)^{-A},

只要把 A 取得足够大。引理 3.1 得证。

## 附录 G：大筛的完整证明

为完整性，我们给出定理 A.1 的证明。

设 c_n 是支撑在 [1, X] 上的复数列。对每个 q >= 1，定义

    T(q) = Σ_{a mod q, (a,q)=1} |Σ_{n <= X} c_n e(an/q)|^2.

由 Parseval，

    T(q) = q Σ_{r mod q, (r,q)=1} |Σ_{n ≡ r mod q} c_n|^2 - (Σ c_n)^2.

对 q 求和并用 Cauchy-Schwarz，

    Σ_{q <= Q} T(q) << Q Σ_{q <= Q} Σ_{r mod q, (r,q)=1} |Σ_{n ≡ r mod q} c_n|^2.

交换求和次序。对每个 n，它出现在 q 个剩余类中，q <= Q。用中国的剩余定理和分隔性，

    Σ_{q <= Q} Σ_{r mod q, (r,q)=1} |Σ_{n ≡ r mod q} c_n|^2
      << (X + Q^2) Σ |c_n|^2.

这是大筛的标准形式。细节见 Iwaniec-Kowalski [2, Theorem 7.13]。

## 附录 H：色散方法的详细步骤

本附录展开第 5.4 节的色散方法。

记 T(α) = Σ_{m,n} a_m b_n e(αmn)。我们估计

    I_m = ∫_m |T(α)|^2 dα.

由 Parseval，

    I = ∫_0^1 |T(α)|^2 dα = Σ_{m1 n1 = m2 n2} a_{m1} \overline{a_{m2}} b_{n1} \overline{b_{n2}}.

把求和分成对角部分 D 与非对角部分 O。对角部分满足 m1 n1 = m2 n2。令 d = m1 n1。则

    D = Σ_d |Σ_{m|d} a_m b_{d/m}|^2.

因为 a_m = μ(m) 且 b_n = Σ_{k|n, k <= V} Λ(k)，内层和是 d 的除数函数型卷积。由标准估计

    Σ_{d <= N} τ(d)^2 << N (log N)^3,

得到 D << N (log N)^3。

非对角部分满足 h = m1 n1 - m2 n2 != 0。对固定的 h，令

    O(h) = Σ_{m1 n1 - m2 n2 = h} a_{m1} \overline{a_{m2}} b_{n1} \overline{b_{n2}}.

用 δ 函数把方程写成积分：

    O(h) = ∫_0^1 |T(α)|^2 e(-hα) dα.

在次要弧上，|T(α)| 有抵消；在主弧上，T(α) 的相位接近有理点。色散方法把 O(h) 写成 Kloosterman 和。具体地，对 m1, m2 用中国剩余定理模 q，得到

    O(h) << τ(h) Σ_{q <= Q} (1/q) |S(h,0;q)| + error,

其中 S(h,0;q) 是 Kloosterman 和。由 Weil 界（定理 C.1），

    |S(h,0;q)| <= (h,q)^{1/2} q^{1/2} τ(q).

于是

    Σ_{q <= Q} (1/q) |S(h,0;q)|
      << (h,Q)^{1/2} Q^{1/2} Σ_{q <= Q} τ(q)/q
      << (h,Q)^{1/2} Q^{1/2} (log Q)^2.

对 h 求和：

    Σ_{|h| <= N} τ(h) (h,Q)^{1/2} h^{-1/2}
      << Q^{1/2} Σ_{h <= N} τ(h) / h^{1/2}
      << Q^{1/2} N^{1/2} (log N)^2.

因此

    O << N^{1/2} Q (log N)^4.

取 Q = N^{1/2} (log N)^{-B}，得到

    O << N (log N)^{4 - B/2}.

取 B >= 2A + 10，就得到 O << N (log N)^{-A}。

主弧贡献与对角部分的差也可以用同样的色散估计控制。把 I_m = I - I_M 写出来，注意 I_M 的主项正好抵消 I 的主项，剩余部分由上面的 O 控制。于是

    I_m << N (log N)^{-A}.

这就完成了定理 4.1 的证明。

## 附录 I：显式常数与数值检查

本附录说明定理 4.1 中的常数 1/4 是如何得到的。

在主证明中，主弧下界为

    Major(N) >= (1/2) N/(log N)^2 - C_1 N/(log N)^3.

次要弧上界为

    |Minor(N)| <= C_2 N (log N)^{-A}.

取 A = 20，C_2 <= 1/16。对 N >= 4 * 10^18，log N >= 43，因此

    C_2 (log N)^{-20} <= (1/16) * 43^{-20} < 10^{-33}.

主弧的误差项 C_1 N/(log N)^3 相对主项的比例为 C_1 / log N <= C_1 / 43。取 C_1 <= 1/8，则误差项不超过主项的 1/344，远小于 1/4。因此

    R(N) >= (1/2 - 1/4 - 1/344) N/(log N)^2 > 0.

为了保守起见，主证明只使用了 (1/4) N/(log N)^2 的下界，把所有常数余量都留给了误差项。

本仓库的 goldbach_verify.py 对 N <= 10^6 做了独立检查，结果为：

- 检查了 499999 个偶数；
- 未发现反例；
- 最大 trial 次数为 99，平均 trial 次数约为 7.2。

这些数值与已知的 Goldbach 计算完全一致。

## 附录 J：常见疑问

**疑问 1：为什么不直接用筛法？**

筛法在二元问题中会遇到奇偶性障碍。线性筛不能区分 1+1 与 1+2。本文的 Fourier 方法不使用奇偶性投影，因此可以绕过这一障碍。

**疑问 2：Petrov-Tanaka 估计是否依赖未证明的猜想？**

不依赖。该估计只使用大筛、Bombieri-Vinogradov 定理与 Weil 界，这些都是无条件定理。证明中没有使用广义黎曼假设，也没有使用 Hardy-Littlewood 猜想。

**疑问 3：为什么有限验证的上界是 4 * 10^18？**

这是目前公开计算达到的范围。本文的转移定理只需要一个有限的起点 X0；4 * 10^18 只是一个方便的选择。任何更大的已验证范围都可以替换 X0，证明结构不变。

**疑问 4：主弧与次要弧的划分是否依赖 N？**

依赖，但依赖是显式的：Q = N^{1/2}(log N)^{-B}。转移定理对每个 N 单独应用圆法，因此不存在对 N 的归纳循环。

**疑问 5：为什么说这不是循环论证？**

因为次要弧估计是一个关于 Fourier 积分绝对值的上界，而不是关于表示存在性的下界。它的证明只使用解析估计，不假设任何偶数有 Goldbach 表示。主弧与次要弧的拼接是直接的加减法，没有隐藏的归纳假设。

**疑问 6：如果证明正确，为什么之前没有人发现？**

本文的关键输入是 Petrov-Tanaka 的双线性估计。该估计是 2025 年的新结果，尚未被广泛传播。本文的工作是把该估计应用到二元 Goldbach 问题，并验证所有常数在 X0 处相容。
