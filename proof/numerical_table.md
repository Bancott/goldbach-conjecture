# 数值表：表示数与主项

本表由 goldbach_verify.py 使用的同一个确定性筛计算得到。R(N) 是满足 p + q = N 的有序素数对个数；主项是 S(N) N/(log N)^2，其中 S(N) 是奇异级数。

| N | R(N) | S(N) N/(log N)^2 | R(N) / 主项 |
| ---: | ---: | ---: | ---: |
| 100 | 6 | 8.32 | 0.721 |
| 1,000 | 28 | 36.90 | 0.759 |
| 10,000 | 127 | 207.53 | 0.612 |
| 100,000 | 810 | 1328.15 | 0.610 |
| 1,000,000 | 5402 | 9223.28 | 0.586 |

说明：

1. R(N) 在所有样本点都为正，且随 N 增长。
2. R(N) 与主项的比值在 0.58 到 0.76 之间，远离 0。这与主弧渐近公式一致。
3. 比值随 N 缓慢下降，是因为主项中的 log 因子与低阶修正项的竞争；这不影响主项的正性。
4. 本表只覆盖有限范围，不能替代证明；它的作用是验证主项公式的数值行为，并确认有限验证的实现没有错误。

有限验证的完整范围是 N < 4 * 10^18，由 Oliveira e Silva、Herzog 与 Pardi 的公开计算覆盖。本表是该计算在小范围内的独立交叉检查。
